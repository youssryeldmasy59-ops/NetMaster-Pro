# ⚡ NetMaster Pro
> **داشبورد التحكم الشامل في أجهزة وسرعة الشبكة والراوتر**  
> Complete Local Network Controller, Bandwidth Limiter & TP-Link Router Manager.

---

## 🌟 المميزات الرئيسية (Features)
- 📡 **فاحص شبكة لحظي (Real-Time Network Discovery)**: يكتشف تلقائياً كل الأجهزة المتصلة بالشبكة (الآي بي، الماك أدرس، زمن الاستجابة Ping، والشركة المصنعة مثل Apple, Samsung, Realme, Xiaomi).
- ⚡ **تحديد سرعة الأجهزة (Bandwidth Throttling)**: إمكانية تحديد سرعة النت لأي جهاز متصل (512 Kbps, 1 Mbps, 2 Mbps, 5 Mbps أو سرعة مخصصة).
- 🚫 **قطع النت الفوري (NetCut / Kill Switch)**: قطع الاتصال بالإنترنت تماماً عن أي جهاز بنقرة زر واحدة عبر إرسال حزم ARP مخصصة.
- 🔄 **إعادة الاتصال (Instant Restore)**: استرجاع الاتصال الطبيعي لأي جهاز في ثوانٍ.
- 🎛️ **تكامل مخصص لراوتر TP-Link VX220-G2v**: فحص الراوتر ودليل تفاعلي مصور لتفعيل الـ Hardware QoS داخل إعدادات الراوتر نفسه لتعمل 24/7 دون الحاجة لتشغيل الكمبيوتر.
- 🎨 **واجهة عصرية فاخرة (Dark Glassmorphism UI)**: تصميم دارك مود فائق الأناقة مع خط عربي أنيق (Cairo) ومؤشرات حالة حية تحدث كل 4 ثوانٍ.

## 🚀 طريقة التشغيل (Quick Start)

### 1. المتطلبات:
- نظام macOS أو Linux
- بايثون 3.9+ أو مدير الحزم فائق السرعة `uv`

### 2. التشغيل المباشر بنقرة واحدة (macOS):
اضغط مرتين (Double Click) على الملف:
```bash
NetMaster.command
```
أو من سطر الأوامر (Terminal):
```bash
./run.sh
```

### 3. للتشغيل بالصلاحيات الكاملة (تفعيل قطع النت وخنق السرعة):
لإتاحة التحكم بالحزم وحقن الـ ARP Spoofing، قم بالتشغيل باستخدام `sudo`:
```bash
sudo ./run.sh
```
